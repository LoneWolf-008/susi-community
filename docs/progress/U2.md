# U2 — Peta dengan marker (MapLibre)

**Branch:** `implement/U2-peta-marker` · **Status:** sedang dikerjakan

## Keputusan: (b) `maplibre-gl` langsung + komponen marker sendiri

1. mapcn dipasang lewat CLI shadcn (`shadcn add @mapcn/map`): butuh shadcn/ui terpasang, alias `@/`, dan token CSS shadcn (`bg-primary`, `bg-background`). Proyek ini Vite + React 19 + **Tailwind v3** tanpa shadcn atau alias, dan tema SUSI memakai warna sendiri.
2. mapcn memuat worker MapLibre dari unpkg (skrip pihak ketiga). `maplibre-gl` langsung menyertakan worker di bundle-nya sendiri (blob), tanpa CDN tambahan.
3. Komponen yang dibutuhkan kecil (`MapView`, marker berwarna, popup, marker geser), jadi menulisnya sendiri lebih murah daripada menyesuaikan mapcn dan tidak menambah dependensi selain `maplibre-gl`.

**Sumber tile:** [OpenFreeMap](https://openfreemap.org), gaya `positron`
(`https://tiles.openfreemap.org/styles/positron`). Gratis tanpa API key atau registrasi, tanpa batas
tampilan, dan boleh untuk penggunaan komersial. Atribusi wajib ("OpenFreeMap © OpenMapTiles Data
from OpenStreetMap") ditambahkan otomatis oleh `AttributionControl` MapLibre dari style. CARTO (bawaan
mapcn) tidak dipakai, karena paket gratisnya dibatasi untuk penggunaan non-komersial.

**CSP:** `helmet()` di backend hanya berlaku untuk respons API (JSON); backend tidak menyajikan HTML
frontend. Frontend disajikan Vite (dev; proxy hanya `/api`) dan Vercel (`vercel.json` hanya rewrite,
tanpa header CSP), dan `index.html` tidak punya meta CSP. Jadi tile (`tiles.openfreemap.org`) dan
worker blob MapLibre tidak terblokir. Bila nanti CSP ditambahkan di hosting frontend, izinkan:
`connect-src https://tiles.openfreemap.org`, `img-src data: blob:`, `worker-src blob:`, `child-src blob:`.
