# U2 — Peta dengan marker (MapLibre)

**Branch:** `implement/U2-peta-marker` · **Status:** selesai. Peta belum diuji di browser (lihat
daftar cek visual untuk T16).

## Keputusan: (b) `maplibre-gl` langsung + komponen marker sendiri

1. mapcn dipasang lewat CLI shadcn (`shadcn add @mapcn/map`): butuh shadcn/ui terpasang, alias `@/`, dan token CSS shadcn (`bg-primary`, `bg-background`). Proyek ini Vite + React 19 + **Tailwind v3** tanpa shadcn atau alias, dan tema SUSI memakai warna sendiri.
2. mapcn memuat worker MapLibre dari unpkg (skrip pihak ketiga). Dengan `maplibre-gl` langsung, worker dibundel Vite dari paket sendiri dan disajikan dari origin aplikasi.
3. Komponen yang dibutuhkan kecil (`MapView`, marker berwarna, popup, marker geser), jadi menulisnya sendiri lebih murah daripada menyesuaikan mapcn dan tidak menambah dependensi selain `maplibre-gl`.

**Versi:** `maplibre-gl` **6.12**. Versi 5.x yang semula terpasang terkena advisory kritis
[GHSA-jrc7-96c5-q579](https://github.com/advisories/GHSA-jrc7-96c5-q579) (XSS di `DOM.sanitize()`,
≤ 6.4.0). v6 berupa ESM dengan worker terpisah, jadi worker diimpor lewat
`maplibre-gl/dist/maplibre-gl-worker.mjs?worker&url` lalu `setWorkerUrl()`.

**Sumber tile:** [OpenFreeMap](https://openfreemap.org), gaya `positron`
(`https://tiles.openfreemap.org/styles/positron`). Menurut situsnya: gratis tanpa API key atau
registrasi, tanpa batas jumlah tampilan, dan boleh untuk penggunaan komersial. Atribusi wajib
("OpenFreeMap © OpenMapTiles Data from OpenStreetMap") ditambahkan otomatis oleh `AttributionControl`
MapLibre dari style. Basemap CARTO (bawaan mapcn) tidak dipakai, dan ketentuannya tidak dicek di sini.

**CSP:** `helmet()` di backend hanya berlaku untuk respons API (JSON); backend tidak menyajikan HTML
frontend. Frontend disajikan Vite (dev; proxy hanya `/api`) dan Vercel (`vercel.json` hanya rewrite,
tanpa header CSP), dan `index.html` tidak punya meta CSP. Jadi tile dan worker MapLibre tidak
terblokir dan tidak ada konfigurasi yang perlu diubah. Bila nanti CSP ditambahkan di hosting frontend,
izinkan: `connect-src https://tiles.openfreemap.org`, `img-src 'self' data: blob:`,
`worker-src 'self' blob:`.

## Catatan

- **Temuan di luar scope:** `GET /communities` (khusus login) mengembalikan alamat dan koordinat persis
  semua komunitas tanpa melihat `show_location`, karena AgenSUSI butuh alamat untuk kunjungan. Peta U2
  sudah memakai data publik, tetapi daftar komunitas di dasbor masih menerima kolom lengkap. Layak
  dibatasi per peran di tugas berikutnya (mis. hanya anggota/pembuat/AgenSUSI/admin).
- Titik kebutuhan seed sama dengan titik komunitasnya, jadi di peta kebutuhan tampil bergeser beberapa
  piksel di sebelah marker komunitas.
- Katalog dan daftar publik dibatasi 50 item per permintaan (cukup untuk data demo).
- `seed --sync-kb` menimpa entri KB di DB dev dengan isi `kb.json`; suntingan KB lewat panel admin di
  DB dev (bila ada) ikut tertimpa.
- Server dev (3009/5173) tidak sedang berjalan; MySQL masih berjalan dari konfigurasi Laragon (lihat U5).

## Temuan T16 (diperbaiki)

Smoke browser T16 menemukan bahwa **semua peta U2 tampil kosong** (tinggi wadah 0 karena
`maplibre-gl.css` menimpa `absolute inset-0`) dan **klik marker membuat peta crash** (`getOffset()`
di MapLibre v6 tidak punya `toArray()`). Keduanya tidak terdeteksi oleh cek API/build U2. Perbaikan dan
hasil uji ada di `docs/progress/T16.md`.
