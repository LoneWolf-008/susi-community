## Catatan / sisa

- `PATCH /liaison/visits/:id` memakai `COALESCE`, jadi kolom opsional tidak bisa dikosongkan lewat ubah
  (mis. menghapus jam). Belum dibutuhkan; dicatat.
- Kolom DATE dikirim mysql2 sebagai ISO UTC. Frontend hanya membandingkan tanggal lewat getter lokal
  (`toDateInput`). Zona waktu server & DB perlu diseragamkan saat deploy (catatan untuk T16).
- Antrean eskalasi masih slot kosong (T14).
