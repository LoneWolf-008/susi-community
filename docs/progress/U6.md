### Seed

Satu eskalasi `assigned`: Ibu Siti → Budi. Isinya dua giliran AI (+ `ask_logs`), pesan konfirmasi
tiket, lalu tiga pesan agen/pengguna. Balasan terakhir agen belum dibaca Siti, sehingga lencana
tampil di Ruang AgenSUSI dan peluncur. Idempoten per id sesi.

## Keputusan desain

- **`requested` vs `waiting`.** Spesifikasi hanya menyebut kedua nilai. Di sini `requested` berarti
  tiket menunggu tetapi belum ada yang bertugas. Keduanya tampil sebagai "Menunggu agen"; bedanya ada
  di `eta_text` dan tombol WhatsApp.
- **Pesan untuk AgenSUSI selalu disimpan**, juga bila "Simpan riwayat chat" dimatikan (T15), karena
  agen harus bisa membacanya. PII tetap disamarkan.
- **Tidak ada perubahan prompt chatbot**, jadi `PROMPT_VERSION` tetap. Teks baru (`handoffCancelledReply`,
  `HANDBACK_REPLY`) adalah jawaban tetap, bukan prompt LLM.
- **Kembalikan ke AI** = tiket `resolved` dengan `handed_back = 1`, sehingga pengguna tetap diminta
  menilai. **Kembali ke asisten AI** oleh pengguna = `cancelled`.

## Verifikasi (Acceptance)

Skrip API satu perintah terhadap server dev 3009 (tanpa browser). Sesi uji dihapus di akhir.

| Langkah | `handoff.status` |
|---|---|
| 1. "apakah ada aplikasi android susi di play store?" → `source=fallback`, `escalation_suggested=true` | `none` |
| 2. Pengguna setuju → tiket #2 | `waiting` ("Biasanya dibalas dalam beberapa menit.") |
| 3. Pengguna menulis saat menunggu → `message: null`, `source: handoff` | `waiting` |
| 4. Liaison claim | `assigned` (agent Budi Santoso) |
| 5. Balasan agen → pesan terakhir `role: agent`, `unread: 1` | `assigned` |
| 6. Pengguna membaca & membalas → `unread: 0` | `assigned` |
| 7. Liaison menyelesaikan | `resolved` |
| 8. Pengguna menilai 5 | `none` |
| 9. Pertanyaan baru → dijawab AI (`source=kb`) | `none` |

**`ask_logs` sesi: 1 sebelum handoff, tetap 1 setelah resolved** (tidak ada panggilan LLM baru
selama handoff), lalu bertambah 1 setelah kembali ke AI. **9/9 cek lulus.**

Cek tambahan lewat API (di luar alur yang diminta):
- **cancel:** tiket → `cancelled`, `handoff: none`, pesan konfirmasi tampil, panggilan ulang
  idempoten, klaim tiket yang batal → 409, pertanyaan berikutnya dijawab AI;
- **handback:** tiket `resolved` + `handed_back`, pengguna melihat `resolved` dan pesan agen bawaan;
  muncul benar di `GET /chatbot/handoffs` dan antrean `status=all`.

## Catatan

- Widget melayang kini memulihkan percakapan tersimpan saat dasbor dimuat (sebelumnya baru saat
  dibuka), agar balasan agen bisa ditandai di peluncur. Ini menambah satu request saat ada sesi
  tersimpan.
- Pengguna yang tiketnya dibuat di tab lain tidak mendapat titik di peluncur, karena id sesi disimpan
  per tab. Pengguna login tetap mendapat notifikasi lonceng dan lencana di Ruang AgenSUSI.
- Evaluasi live chatbot tetap ditunda ke T16.
