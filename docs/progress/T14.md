# T14 — Chatbot FE: widget terpadu + panel liaison/admin

**Branch:** `implement/T14-chatbot-fe` · **Status:** selesai

## Yang dibangun

### Widget Tanya SUSI

Satu widget menggantikan dua chatbot lama yang memakai KB hardcoded ganda: `AskSusiPanel` (publik)
dan `AiAgent` (dasbor). Berkasnya `components/chat/ChatWidget.jsx`, `ChatPanel.jsx`,
`MarkdownLite.jsx`, dan hook `hooks/useChat.js`.

| Bagian | Isi |
|---|---|
| Varian | **Overlay** layar penuh di halaman publik, dibuka dari saran landing/navigasi (pertanyaan awal langsung dikirim). **Tombol melayang** di dasbor Komunitas, Talenta, dan AgenSUSI. Mode publik/masuk mengikuti AuthContext |
| Streaming | `POST /chatbot/stream` lewat `fetch` + `ReadableStream` (`api.stream`, refresh token sekali bila 401). Teks akhir selalu dari `done` (menangani `replace`). Ada indikator mengetik, tombol **Hentikan** (abort), dan **Coba lagi** saat gagal. Server tak terjangkau → satu pesan offline minimal |
| Markdown aman | Paragraf, **tebal**, daftar, dan tautan hanya http/https; semuanya lewat React, tanpa `dangerouslySetInnerHTML` |
| Saran cepat | `GET /chatbot/suggestions` per peran. Landing & navigasi memakai saran publik yang sama (`data/askSuggestions.js`) dan diuji selalu terjawab KB, menggantikan saran pemasaran lama yang berujung "belum tahu" |
| Umpan balik & eskalasi | 👍/👎 per jawaban. Tombol **Hubungi AgenSUSI** muncul saat `escalation_suggested`; anonim mengisi kontak balik. Banner status tiket; WhatsApp resmi bila tidak ada AgenSUSI yang bertugas. Balasan agen di-polling (8 detik, hanya saat widget terbuka & tab aktif) |
| Transparansi | Header "ASISTEN AI · JAWABAN BISA KELIRU"; setiap jawaban berlabel **TANYA SUSI · AI**. Balasan manusia berlabel **AGENSUSI · TIM SUSI** dengan warna berbeda |
| Sesi | ID sesi di `sessionStorage` per pengguna (anonim: `anon`); sesi milik pengguna dijaga server. Saat pengunjung masuk, percakapan anonimnya diadopsi (diklaim server di pesan berikutnya). Riwayat dimuat ulang setelah reload |
| Aksesibilitas | `role="dialog"` + `aria-modal`; fokus awal ke kolom tanya; Tab terkunci di dalam panel; Esc menutup; fokus kembali ke pemicu. Log `aria-busy` saat streaming; `aria-live` hanya mengumumkan jawaban yang sudah lengkap |
| Pembersihan | `AiAgent.jsx`, `AskSusiPanel.jsx`, dan `utils/askSusi.js` dihapus. Tidak ada lagi array KB di FE |

## Bug yang ditemukan lewat uji browser

1. **Overlay tidak pernah tampil di landing.**
   - Gejala: saat halaman dimuat (overlay tertutup), efek animasi keluar menjadwalkan
     `setMounted(false)` padahal nilainya sudah false.
   - Penyebab: update tertunda itu (prioritas default) menimpa `setMounted(true)` saat render
     sinkron dari klik, sehingga dialog dilepas dari DOM padahal `open` = true. Kunci scroll dan
     pertanyaan awal tetap berjalan.
   - Perbaikan: pelepasan hanya dijadwalkan bila overlay sedang terpasang.
   - Pola lama di `AskSusiPanel` sama, tetapi alur ini tidak pernah teruji.
2. **Balasan AgenSUSI bisa terlewat.**
   - Gejala: polling memakai `after = id terbesar yang diketahui`. Bila pengguna mengirim pertanyaan
     baru setelah agen membalas, id pertanyaan baru lebih besar, sehingga balasan agen tidak pernah
     terambil.
   - Perbaikan: acuan polling hanya maju dari data server (pemulihan/polling); pesan digabung
     berurutan menurut id.
3. **Esc tidak menutup setelah eskalasi.**
   - Gejala: tombol yang sedang fokus hilang saat form diganti, sehingga fokus jatuh ke `<body>`.
   - Perbaikan: listener di tingkat dokumen (tombol untuk Modal lain diabaikan); fokus dipindah ke
     kolom tanya setelah eskalasi; Tab dari luar panel kembali ke dalam.

## Verifikasi (Acceptance)

Uji browser (Chrome/Playwright, DB sekali pakai `susi_community_e2e`, BE 3019 dengan
`LLM_PROVIDER=mock`, FE 5181): **35/35 cek lulus**.

Alur lengkap sesuai acceptance:
1. anonim bertanya dari saran landing (SSE `text/event-stream`), 👍 tersimpan;
2. jawaban LLM (mock) bertahap;
3. pertanyaan tak terjawab → "belum tahu" + tombol eskalasi → kontak → tiket & banner;
4. AgenSUSI melihat "1 menunggu" di Beranda → klik notifikasi → tiket terbuka dengan kontak balik
   → klaim → balas;
5. pengunjung membuka widget lagi: riwayat pulih, balasan berlabel AgenSUSI muncul lewat polling,
   status DITANGANI;
6. AgenSUSI menyelesaikan + draft KB;
7. admin melihat statistik, menyetujui draft "DARI ESKALASI #1", dan pertanyaan tak terjawab
   tercantum;
8. pengunjung baru menanyakan hal serupa → **dijawab dari entri KB baru tanpa tawaran eskalasi**.

Widget dasbor di **360 px**: panel 336×600 tanpa scroll horizontal, saran khusus komunitas, fokus
awal di kolom tanya, Tab terkunci, data pribadi milik pengguna, Esc menutup dan fokus kembali ke
tombol. Tanpa galat konsol.
