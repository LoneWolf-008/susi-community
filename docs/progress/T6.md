## Perbaikan bug T4

`TransitionProvider` diam-diam membuang navigasi yang diminta selama transisi berjalan (±1,1 detik).
Akibatnya klik "Ajukan Kebutuhan" tepat setelah masuk tidak melakukan apa-apa. Kini permintaan
terakhir diantre dan dijalankan setelah transisi selesai. Skenario ini ikut diuji di acceptance
(klik segera setelah login).

## Database lokal

- Atas permintaan user, DB kerja diganti ke `susi_community_db` (`backend/.env` dan `.env.example`).
- Isi impor user adalah skema dump asli: tanpa migrasi 001–004, tanpa dua CHECK, tanpa
  `schema_migrations`, dan 0 baris di 31 tabel (dihitung per tabel). Karena kosong, DB dibangun
  ulang dengan `npm run db:reset` + `npm run seed`. Strukturnya kini identik dengan DB dev
  (dibandingkan lewat `information_schema`).
- `susi_community` dan `susi_community_dev` tidak disentuh.
- Default collation database `susi_community_db` adalah `utf8mb4_0900_ai_ci` (dari saat impor).
  Semua tabel tetap eksplisit `utf8mb4_unicode_ci`; migrasi berikutnya wajib menulis charset dan
  collation secara eksplisit.
