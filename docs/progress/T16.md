### Bug yang ditemukan smoke browser (sudah diperbaiki)

1. **Semua peta kosong (U2).** `maplibre-gl.css` dimuat setelah Tailwind dan memberi `.maplibregl-map
   { position: relative }`, sehingga kelas `absolute inset-0` kalah dan tinggi wadah peta menjadi 0.
   Tile tetap terunduh, sehingga cek API/build U2 tidak menangkapnya. Perbaikan: posisi wadah lewat
   gaya inline.
2. **Klik marker membuat peta crash.** `Marker.getOffset()` di MapLibre v6 mengembalikan `Point {x, y}`
   (tanpa `toArray()`); error boundary lalu menampilkan "peta gagal dimuat".
3. **Marker kebutuhan menutupi marker komunitas.** Titik kebutuhan dibulatkan 3 desimal sedangkan titik
   komunitas sendiri tidak, sehingga tidak dianggap bertumpuk. Kini dikelompokkan per sel 3 desimal dan
   disebar 30 px.
