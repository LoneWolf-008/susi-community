# U3 (ringan) + 3 item U4 — Tampilan mobile & performa

**Branch:** `implement/U3-responsive` · **Status:** selesai sesuai scope ringan (lihat "Belum dikerjakan")

## A. Audit 360 × 740 (sebelum & sesudah)

`npm run audit:mobile` (`frontend/scripts/audit-mobile.mjs`) menjalankan Playwright Chromium headless
dengan emulasi ponsel (layar sentuh, 360 × 740). Untuk tiap peran, skrip login lewat API lalu membuka
semua rute **dan semua tab dasbor**: publik (7 rute), komunitas (dasbor + 5 tab, `/ajukan`,
Ruang AgenSUSI), talenta (dasbor + 7 tab, Ruang AgenSUSI), AgenSUSI (dasbor + 9 tab), dan admin (dasbor +
9 tab), total 45 halaman. Yang dicatat:
- scroll horizontal dokumen;
- elemen yang melewati tepi kanan, termasuk yang tersembunyi `overflow-x-hidden` di div akar (dekorasi
  tetap seperti `noise-overlay` tidak dihitung);
- elemen interaktif < 40 px;
- input < 16 px.

| | Sebelum | Sesudah |
|---|---|---|
| Halaman dengan scroll horizontal | 0 / 45 | **0 / 45** |
| Halaman dengan elemen melewati tepi kanan | 0 / 45 | **0 / 45** |
| Target sentuh < 40 px | 524 | **18** |
| Input < 16 px (zoom iOS) | 42 | **0** |

Temuan terparah sebelum perbaikan: tombol bilah tab mobile DashShell setinggi 31 px (≈ 300 kemunculan),
tombol `chip-mono` 25 px, marker & kontrol peta 24–36 px, dan input 14 px di form/pengaturan.

Sisa 18 target kecil:
- 15 adalah link atribusi peta ("OpenFreeMap", "© OpenMapTiles", "OpenStreetMap"): teks lisensi wajib
  dan berupa link inline;
- 3 ada di halaman Auth publik (`← KEMBALI…` di `/masuk` & `/admin`, tombol "LIHAT" kata sandi), yang
  termasuk polesan Auth dan dilewati.

## Belum diuji di browser / perangkat nyata (untuk T16)

Audit hanya mengukur tata letak, bukan interaksi:
1. Drawer: buka/tutup (Menu, Esc, ketuk latar), fokus, tab aktif di bilah bawah; sheet notifikasi
   (tutup, hapus, buka notifikasi).
2. Bottom sheet modal (mis. Selesaikan eskalasi, form di modal): gulir internal, Esc, ketuk latar.
3. **Keyboard virtual di ponsel nyata** (iOS Safari & Chrome Android): kolom tulis Tanya SUSI tidak
   tertutup, tidak ada zoom saat fokus input.
4. Halaman dengan safe-area (iPhone dengan notch / home indicator): bilah bawah, drawer, bottom sheet.
5. Lazy loading: placeholder sesaat saat pindah rute/dasbor pertama kali; tidak ada layar putih.
6. Font woff2 termuat (tidak ada 404 `/fonts/*.woff2`), tidak ada lonjakan tata letak berarti.
7. `prefers-reduced-motion` aktif: transisi langsung, animasi dasbor seketika.
