# R3 — Chatbot personal: profil, karier, rekomendasi

**Branch:** `implement/R3-chatbot-personal` · **Status:** selesai. Evaluasi live ditunda ke T16.

## Yang dibangun

| Bagian | Isi |
|---|---|
| Konteks personal | `services/chatbot/personalContext.js`: ringkasan dari `req.user.id` di server, tanpa email/telepon, cache 60 detik. Talenta: keahlian, level & poin, proyek selesai, lamaran aktif, 3 rekomendasi teratas (mesin R1), kesenjangan keahlian dari kebutuhan terbuka, status sertifikasi. Komunitas/AgenSUSI: kebutuhan aktif dan talenta teratas per kebutuhan (hanya kolom yang boleh dilihat pemilik). Disuntikkan sebagai `<user_profile>` dan `<recommendations>` |
| Intent baru | `rekomendasi_proyek`, `rekomendasi_talenta`, `karir`, `sertifikasi` (`services/chatbot/personal.js`). Arah rekomendasi ditentukan peran. Permintaan daftar dijawab dari template tanpa LLM; LLM hanya untuk "kenapa" dan narasi karier (maks. 450 token), dengan cache per hash profil + rekomendasi |
| Prompt `r3.1` | Tanpa janji gaji/kerja/penempatan, tanpa klaim pasar kerja di luar data, tanpa profil orang lain, saran belajar umum diberi label, mengakui profil yang masih kosong |
| Kartu | Respons dan event `done` membawa `cards` (`need` / `talent`, dengan `id`, `score`, judul, status undangan/lamaran). Tidak disimpan di `chat_messages`, jadi tidak muncul lagi saat riwayat dipulihkan |
| Privasi | Migrasi `011_ai_personalization.sql`: `user_settings.allows_ai_personalization` (bawaan 1) lewat `PATCH /settings`. Bila mati, atau `allows_ai_chat` mati, jawabannya umum |
| FE | `ChatCards.jsx`: talenta mendapat **Lihat & lamar**, pemilik mendapat **Lihat** dan **Undang**. `lib/chatNavigation.js`: event `susi:open-need` / `susi:open-owner-need` yang ditanggapi dasbor talenta, komunitas, dan AgenSUSI. Saklar **Personalisasi Tanya SUSI** di Pengaturan → Privasi. Saran cepat per peran (dari `GET /chatbot/suggestions`) |
| Golden set | +18 kasus (total 79): personal (8), karier (5), privasi (2), sertifikasi (3). Mencakup talenta tanpa keahlian, tidak mengarang proyek di luar rekomendasi, pemilik lain tidak melihat kebutuhan pihak lain, pertanyaan gaji/kerja tetap, personalisasi mati, syarat vs status sertifikasi. `evalCore` memeriksa jumlah dan tipe kartu |

membandingkan id kartu dengan 3 teratas rekomendasi. Sesi chat uji dihapus sesudahnya.

## Catatan

- **Evaluasi live ditunda ke T16** atas keputusan pengguna, karena prompt masih akan berubah di U6.
- Kartu chat belum diuji di browser (atas permintaan, acceptance hanya lewat API). Uji klik
  **Lihat & lamar** / **Undang** dari widget masuk ke uji browser T16.
- Kebutuhan terbuka di data seed masih sedikit, jadi tiga dari empat talenta mendapat kurang dari
  3 kartu (sama dengan catatan R2).
