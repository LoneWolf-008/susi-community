# T0 — Repo hygiene & baseline

**Branch:** `chore/T0-repo-hygiene` · **Status:** selesai

## Yang dikerjakan

1. **Snapshot WIP.** Perubahan frontend yang belum di-commit (embed Google Maps, alur
   kirim/verifikasi hasil, `projectSubmissions.js`) di-commit apa adanya sebagai baseline.
2. **Dokumen.** `TASKS-SUSI-ClaudeCode.md` dipindah ke `docs/TASKS.md`; PRD, SDD, dan
   addendum F7 disalin ke `docs/`. `docs/README.md` menjelaskan bahwa SDD memakai skema
   lama (`kebutuhan`, `lamaran`) dan mana yang berlaku bila berbeda dengan kode.
3. **`.gitignore` root** + `git rm -r --cached node_modules` (6.119 berkas keluar dari index).
   `frontend/dist` dan `backend/node_modules` memang belum ter-track. `package-lock.json`
   kosong di root (artefak `npm install` yang salah folder) dihapus.
4. **`.gitattributes`** (`* text=auto eol=lf`, biner ditandai) di commit terpisah. Index
   ternyata sudah LF, jadi commit itu hanya berisi `.gitattributes`; working tree lalu
   di-checkout ulang agar ikut LF.
5. **`git add backend`** tanpa `.env` sebagai baseline (commit terpisah dari perbaikan).
6. **`backend/config/env.js`**: memuat `backend/.env` dengan path absolut, memvalidasi
   `DB_HOST/PORT/USER/NAME`, `JWT_ACCESS_SECRET`, `JWT_REFRESH_SECRET`, `FRONTEND_URL`.
   Tambahan: kedua secret harus berbeda; di production secret ≥ 32 karakter dan
   `DB_PASSWORD` wajib. Fallback `dev_*` di `utils/jwt.js` dihapus.
7. **`multer` + `helmet`** masuk `package.json`. `npm ci` sebelumnya akan gagal karena
   lockfile sudah memuat multer tetapi `package.json` tidak.
8. **`helmet()`**, **`trust proxy`** (env `TRUST_PROXY`, default `1`), CORS dari
   `FRONTEND_URL` (boleh beberapa origin dipisah koma).
9. **Folder unggahan** dibuat saat boot. Route memakai `__dirname` sedangkan controller
   memakai `process.cwd()`, sehingga unduhan gagal bila server dijalankan dari folder
   lain. Keduanya kini memakai `env.deliveriesDir` (bisa diarahkan via `UPLOAD_DIR`).
10. **Port dev disamakan ke 5173**: `vite.config.js` memakai `strictPort` agar Vite tidak
    pindah ke 5174 diam-diam (kemungkinan asal nilai 5174 di `.env` lama).
11. **README root**: prasyarat, cara menjalankan BE/FE, tabel env.
