## Catatan untuk T16 (deploy)

- **Batas rate global 500 request / 15 menit per IP.** Pengguna di balik satu IP bersama (jaringan sekolah, NAT operator seluler) berbagi kuota. Dasbor yang mem-polling notifikasi tiap 30 detik (±30 request/15 menit per tab) ditambah pemakaian normal bisa menghabiskannya untuk satu kelompok. Pertimbangkan kunci per pengguna untuk request yang ber-token, atau menaikkan `RATE_LIMIT_MAX`, dan pastikan `TRUST_PROXY` benar. Saat uji otomatis, server uji dijalankan dengan `RATE_LIMIT_MAX=100000`.
- Zona waktu server & DB perlu diseragamkan (catatan T8).
- Bundle 669 KB; code-splitting per dasbor.
